# Instructor Clarification — A02 Deliverables

The written assignment directions contain overlapping references to a presentation, report, reflection, and contribution journal. During the in-class discussion, the instructor clarified the intended format for this assignment.

## Clarified approach

- Each student covers **two comparison topics**.
- Each student prepares **two slides** for those two topics.
- The individual slides are combined into one group presentation with an introduction and conclusion/reflection.
- The group also submits one **combined Contribution Journal** containing each student's individual contribution.
- The instructor stated that the **presentation** and **Contribution Journal** count as the **two deliverables** for this assignment.
- A separate reflection journal is not required because the slides themselves can address what was learned.
- Based on that clarification, this repository treats the slide deck as the project/report content rather than creating a separate one-page written report.

## Working submission plan

1. Final group presentation slide deck
2. Final combined Contribution Journal PDF
3. GitHub repository link submitted in Canvas as instructed
