# A02 Assignment Instructions

## A Comparative Analysis of Machine Learning and Deep Learning Tools and Frameworks

### Research
Choose two tools/frameworks/libraries/repositories per comparison and address:

- **Background:** origin, development, and purpose
- **Key Features:** distinguishing features and advantages
- **Real-world Applications:** examples, case studies, or success stories
- **Comparative Perspective:** usability, performance, support, and scalability

Use reliable sources such as official documentation, scholarly articles, reputable technical blogs, and user reviews.

### Presentation
The presentation should include:

- Introduction
- Detailed findings
- Optional demonstration
- Conclusion with comparative insights
- Smooth transitions and coherent group delivery

### Submission
The assignment instructions require:

- Presentation slides
- One-page report for one comparison
- Contribution Journal PDF documenting every student's contribution
- Git repository containing the required documents
- Git repository link submitted in Canvas

### Naming convention

- Presentation: `A02a_TeamName_SubmitterName_ITA2376`
- Report: `A02b_TeamName_SubmitterName_ITA2376`

### Important grading note
The contribution journal is mandatory. The assignment states that if a student's contribution is not documented, that student receives no individual contribution credit.
