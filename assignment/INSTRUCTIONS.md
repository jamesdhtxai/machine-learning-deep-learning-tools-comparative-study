# A02 Assignment Instructions

## A Comparative Analysis of Machine Learning and Deep Learning Tools and Frameworks

### Research
Each student covers two comparison topics and addresses:

- **Background:** origin, development, and purpose
- **Key Features:** distinguishing features and advantages
- **Real-world Applications:** examples, case studies, or success stories
- **Comparative Perspective:** usability, performance, support, and scalability

Use reliable sources such as official documentation, scholarly articles, reputable technical blogs, and user reviews.

### Presentation
The group presentation should include:

- Introduction
- Detailed findings
- Two comparison slides per student
- Optional demonstration if applicable
- Conclusion / reflection with comparative insights
- Smooth transitions and coherent group delivery

## Instructor clarification
The written assignment directions contain language about a one-page report, but the instructor clarified in class that, for this assignment, the **two deliverables are**:

1. **Presentation in slide form** — each student covers two topics in two slides. The slides serve as the project/report content and can also show what was learned.
2. **Combined Contribution Journal in document/PDF form** — each student writes an individual contribution entry and the group combines the entries.

The instructor also clarified that a separate reflection journal is not required for this assignment because the presentation itself can address what was learned. A separate one-page written report is therefore not being treated as a third deliverable for this project.

### Naming convention

- Presentation: `A02a_TeamName_SubmitterName_ITA2376`
- Contribution Journal: use a clear final PDF filename identifying the team and assignment

### Important grading note
The Contribution Journal is mandatory. Every student must be represented in the final combined journal to receive individual contribution credit.
