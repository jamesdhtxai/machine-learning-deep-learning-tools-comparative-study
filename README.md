# Machine Learning & Deep Learning Tools — Comparative Study

A comparative study of modern **machine learning, deep learning, AutoML, NLP, numerical-computing, and AI developer tools**, focused on understanding how they differ in purpose, architecture, workflow, performance, support, and scalability.

## What this project demonstrates

This project reflects my effort to understand AI/ML tools from **first principles**, not just memorize feature lists. I worked backward from basic questions such as:

- What is a tensor?
- What is a machine-learning framework?
- What is the difference between a library, framework, and platform?
- How is traditional machine learning different from deep learning?
- What changes when computation moves from one machine to a distributed system?

That foundation made the tool comparisons more meaningful and helped me understand when one technology is a better fit than another.

## Skills and concepts demonstrated

- Traditional machine learning vs. deep learning
- Tensors and neural-network training fundamentals
- Regression, classification, decision trees, random forests, and boosting
- AutoML and model-selection workflows
- Single-node vs. distributed computing
- CPU, GPU, and TPU acceleration
- NLP pipelines and pretrained transformer models
- AI-assisted software development
- Technical research and source evaluation
- Comparative analysis across usability, performance, support, and scalability
- Communicating technical differences to a non-specialist audience

## My contribution

My research focused on:

### Scikit-learn vs. H2O
I studied the difference between a **Python machine-learning library** and a **distributed machine-learning platform**, including classic ML tasks, AutoML, model-selection workflows, and single-node vs. distributed computing.

### TensorFlow vs. PyTorch
I refreshed tensor fundamentals and the neural-network learning process, then compared the two deep-learning frameworks across usability, performance, ecosystem support, scalability, and real-world use.

I also helped develop the presentation's opening thesis, transitions, and conclusion so the comparisons connected into one larger learning story.
