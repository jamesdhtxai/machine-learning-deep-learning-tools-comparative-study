# Presentation

Place the working and final presentation files in this folder.

Based on the instructor's in-class clarification, the presentation is one of the **two final deliverables** for A02 and serves as the main project/report content.

Each student is expected to cover **two comparison topics in two slides**, and the group combines the individual slides into one presentation with an introduction and conclusion/reflection.

Required presentation filename format from the assignment:

`A02a_TeamName_SubmitterName_ITA2376`

Before final submission, verify:

- All assigned comparison pairs are represented
- Each comparison includes background, strengths/features, real-world applications, and direct comparison
- Usability, performance, support, and scalability are explicitly addressed where required
- Sources are visible or otherwise clearly documented
- The opening and conclusion connect the individual comparisons into one coherent presentation
- The slides reflect what the group learned, so a separate reflection journal is not required for this assignment
